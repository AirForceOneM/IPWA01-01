Sicherheit

Die Anwendung verarbeitet Benutzereingaben ausschließlich auf der Clientseite und nutzt diese nur zur Filterung und Sortierung der vorhandenen Datensätze. Eingegebene Inhalte werden nicht als HTML interpretiert oder in ausführbaren Code umgewandelt.

Die Darstellung der Tabelleninhalte erfolgt über sichere DOM-Methoden. Neue Zellen werden per JavaScript erzeugt und mit textContent befüllt. Dadurch wird verhindert, dass eingegebene Inhalte als HTML in das Dokument eingefügt und ausgeführt werden.

Zusätzlich werden nur erwartete Filterwerte verarbeitet. Die Eingaben dienen ausschließlich der Suche innerhalb der vorhandenen Datenbasis. Auf potenziell unsichere Verfahren wie das direkte Einfügen von Benutzereingaben per innerHTML wird bewusst verzichtet.

Rechtliche Hinweise

Die angezeigten CO₂-Emissionsdaten sind fiktiv und dienen ausschließlich der Veranschaulichung der implementierten Filter-, Such- und Sortierfunktionen im Rahmen der Fallstudie.
